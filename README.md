# 学習ログ

HTML/CSS/JavaScriptとlocalStorageで動く、日々の学びを記録するシンプルな学習ログアプリです。

学習した日、学習の手ごたえ、学んだことや気づきを記録できます。記録はこのブラウザ内に保存され、日付ごとに一覧・検索・編集できます。最近の学習の手ごたえもグラフでふりかえれます。

## 起動方法

`index.html` をブラウザで開くだけで使えます。ビルドやサーバー起動は不要です。

```text
├── index.html
├── styles.css
├── app.js
├── README.md
└── LICENSE
```

## 機能

- 今日の日付を自動セット
- 学習の手ごたえを5段階で記録
- 学んだことや気づきを記録
- 日付ごとに1件の記録として保存（同じ日付で保存すると上書き）
- 学習記録の一覧表示、編集、削除
- 学びや気づきの検索、手ごたえでの絞り込み
- 最近7件の学習の手ごたえをグラフで表示

## 個人情報と保存先

氏名、学校名、住所、連絡先などの個人情報は入力しないでください。記録はブラウザのlocalStorageに保存され、このアプリから外部へ送信されません。共有端末では記録を他の利用者が見られる可能性があるため注意してください。

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

外部ライブラリは使っていません。

## localStorage

保存キーは `tiny-diary.entries.v1` です。既存の記録との互換性を保つため、キーとデータ形式は変更していません。

記録は次のような配列で保存されます。

```json
[
  {
    "id": "example-id",
    "date": "2026-04-29",
    "mood": "happy",
    "note": "分数の計算方法を復習した",
    "createdAt": "2026-04-29T10:00:00.000Z",
    "updatedAt": "2026-04-29T10:00:00.000Z"
  }
]
```

手ごたえは5段階で記録され、保存データ上では既存形式との互換性のため `mood` として保持されます。
